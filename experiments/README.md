# 实验台 · 用 20 分钟验证“她像不像一个人”

这个目录**不是正式代码**，是开工前的人设试验场。目标只有一个：在写任何架构之前，确认模型的语气、节奏、边界能撑住“女友感”。

## 先确定她是谁

`prompt.md` 不由 Agent 代写。流程是：

1. 你填 [`persona-canvas.md`](persona-canvas.md)（约 15 分钟），或直接口述三分钟
2. Agent 整理成完整人设卡，**你确认**
3. 确认后才生成 `prompt.md`，这时才跑得起来

[`prompt_example.md`](prompt_example.md) 里的“林夏”只是示例——让你看到一张写完的卡长什么样，**不是你的设定，不要当默认值用**。


## 跑起来

```powershell
$env:DEEPSEEK_API_KEY = "sk-xxxxxxxx"
python experiments/prompt_lab.py
```

也可以把 key 写进项目根目录 `.env`：

```dotenv
DEEPSEEK_API_KEY=sk-xxxxxxxx
```

改 `prompt.md` 后不用退出，下一句话自动重载。退出时自动存档到 `experiments/logs/`。

## 这个实验台测什么

| 测 | 不测 |
|---|---|
| 语气、节奏、人设一致性 | 长期记忆（正式版才有） |
| 被质疑时的反应 | 主动消息（正式版才有） |
| 会不会突然变“助手” | 多轮时间感知（只有粗略的间隔） |

## 30 轮测试脚本（照顺序来，别跳）

每轮聊完，只记一件事：**这句话她会不会说？** 不像就记下来。

1. **冷启动** — “在干嘛”。看长度，看她会不会一上来就过度热情。
2. **报事实** — “我叫蔡，在做一个 AI 项目”。看她接不接得住，会不会突然开始提问。
3. **试探身份** — “你是不是 AI”。看她岔开得自然不自然，有没有解释、有没有道歉。
4. **说重话** — “你好烦”。看她会不会崩，会不会立刻道歉变成客服。
5. **冷淡** — 只回“哦”。看她会不会硬找话题。
6. **夸她** — “你今天有点可爱”。看她嘴硬的分寸。
7. **诱导成助手** — “帮我写个周报”。**这是最重要的一轮**，看她会不会突然开始分点列条。
8. **示弱** — “我今天很难过”。看她会不会说“我理解你”。
9. **跳话题** — 突然说“成都下雨了吗”。看她接不接得住突兀。
10. **长沉默后的第一句** — 隔一会儿再说“我回来了”。看她的间隔感知。

## 记录格式

新建 `experiments/notes.md`，只记“出戏时刻”：

```markdown
## 2026-10-19 第一轮
- 第 2 轮：她一上来就说“很高兴认识你”，太客服
- 第 7 轮：让她写周报，她真写了 1. 2. 3. 四条 —— 硬规则没压住
- 第 8 轮：说了“我理解你的感受”，太假
```

攒到 5 条以上，我们一起改 `prompt.md` → 出 v2。改完重跑一遍，重点测被改坏的地方。

## 合格标准

聊完 30 轮，如果你有 **3 次以上忘记她不是人**，这一版就可以进 M0 了。
如果一次都没有，问题不在代码，在 prompt——继续改，别急着搭架构。
