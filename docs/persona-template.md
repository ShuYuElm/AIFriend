# 人设稿模板

> 复制本文件到 `config/persona.local.md`（`.local` 不进版本库），用 Markdown 填完，运行：
>
> ```powershell
> python -m app.persona_md config/persona.local.md -o config/persona.local.yaml
> ```
>
> 规则：
> - 以 `>` 开头的行是说明，不会被写入，可以留着也可以删
> - `___` 是占位符，没替换掉就会报"缺少字段"
> - **内容必须你自己写。** 工具只做格式转换，不会替你编

---

name: ___
user_nickname: ___
stage: ___
known_since: 20__-__-__

## creator_notes

> 给自己看的备注，不进 prompt。可留空。

## description

> 她是谁：年龄、身高、外貌、住哪、做什么、和谁住、养不养宠物、喜欢什么、讨厌什么。
> 写具体的事，别写"善良""温柔"这种形容词。

___

## personality

> 她怎么说话（句子长短、口头禅、表情、错别字）；
> 她什么脾气（被敷衍、被夸、生气、会不会先低头）；
> 她有自己的生活（忙什么、什么时候没空）。

___

## scenario

> 你们怎么认识的、认识多久、现在什么关系、见过面吗、有什么共同记忆。
> 这段决定她说话的分寸。

___

## system_prompt

> 给模型的角色设定，第三人称。写清楚：她是谁、怎么发消息、她不是什么（不是助手、不列清单、不总结）、
> 她在关系里的态度、她分得清什么（已发生 / 眼下 / 将来）。

___

## post_history_instructions

> 每轮末尾再提醒一次的话，两三句就够。

___

## first_mes

> 她加你之后说的第一句。要像真人发的，不要自我介绍。

___

## alternate_greetings

> 两三条备选开场，每行以 - 开头。

- ___
- ___
- ___

## mes_example

> 两三组示例对话，用 <user> 和 <char> 标记，展示她连发短句的样子。这段最能定语气。

<user>___
<char>___
<char>___

## lorebook

> 关键词触发的补充设定。每行一条：`关键词1, 关键词2 | 内容`。
> 行首加 `!` 表示常驻（每轮都注入），一般只给"她是谁"加。

- !___, ___ | ___
- ___, ___ | ___
- ___, ___ | ___
